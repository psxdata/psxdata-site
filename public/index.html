      How it fits together

      One open-source core does the hard part. Everything else is built on it.

      1. SourcePSX public websiteMarket board, historical pages, index and sector data
      2. Corepsxdata libraryScrapes, cleans, validates and caches it into tidy tables
        • Python libraryDataFrames for notebooks and scripts
        • REST APIJSON for apps and spreadsheets
        • MCP serverPSX data inside Claude
        • Analytics warehouseDaily indicators, rankings and returns

      • Checked, not just scraped

        Every price row is validated. Impossible highs and lows, duplicate dates and out-of-order rows are flagged instead of passed on silently.

      • Fast and gentle

        Results are cached, requests are rate limited and retried with backoff, so your code stays fast and the exchange's site isn't hammered.

      • Tested every day

        Integration tests run against the live site every night, a weekly check catches page-layout changes, and this page is rebuilt with psxdata every weekday.

      Questions

      Is it really free?

      Yes. The library, the API and the MCP server are free and MIT licensed. There's no paid tier. The hosted API is rate limited to 60 requests a minute per IP so it stays free for everyone.

      Is this official PSX data?

      psxdata isn't affiliated with the Pakistan Stock Exchange. It reads the data the exchange publishes on its public website and tidies it up. For anything that matters, check against the exchange.

      How fresh is the data?

      Quotes and the screener follow the exchange's market board, which updates during trading hours but isn't tick by tick. Historical prices are daily, up to the last close.

      Are prices adjusted for splits and dividends?

      No. Prices are as the exchange reports them, not adjusted for splits, bonus shares or dividends. Keep that in mind for long backtests.

      Can I use it in a commercial project?

      The code is MIT licensed, so yes. The underlying data comes from the exchange, so check its terms for your use.

      Which tool should I start with?

      Writing Python? Use the library. Building an app or a spreadsheet in another language? Use the REST API. Not a programmer? Connect it to Claude and ask questions.
