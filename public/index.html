Pakistan Stock Exchange data, one line of Python away.

psxdata is a free, open-source library for PSX data: historical prices, live quotes, KSE-100 constituents, sectors, the screener and company fundamentals. Use it from Python, over HTTP, or by asking Claude.

pip install psxdata

Get started View on GitHub

Three ways to use it

Same data underneath. Pick the one that fits how you work.

  1. Python library

    Install from PyPI and get pandas DataFrames back. Built-in caching, retries and proxy support. Python 3.11+.

    Getting startedPyPI

  2. REST API

    Plain JSON over HTTP for any language or spreadsheet. Stocks, quotes, history, indices, sectors, screener and more. Free, 60 requests a minute.

    API docs

  3. Claude, through MCP

    Ask questions in plain English and Claude answers with the numbers. Runs locally in Docker as a Claude Code plugin or Claude Desktop extension. A hosted, no-install version is invite-only for now.

    How it worksSet it up

What data you get

Historical prices
Daily open, high, low, close and volume for any listed stock.
Live quotes
The current market board for a ticker.
Indices
KSE-100, KSE-30, KMI-30 and others, with each stock's weight.
Sectors
All 37 sectors with their aggregates and member stocks.
Screener
Price, P/E, dividend yield and one-year change across the market.
Fundamentals
The financial reports each company has filed.
Debt market
TFCs, sukuks and other listed debt instruments.
Margin-eligible stocks
The current list of eligible scrips.

Good to know. Data comes from the exchange's public website. Quotes aren't tick by tick, prices aren't adjusted for splits or bonus shares, and nothing here is investment advice.
